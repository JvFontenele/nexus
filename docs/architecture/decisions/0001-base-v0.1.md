# ADR-0001 — Base da v0.1: orquestrar ferramentas existentes

Data: 2026-10-24 · Status: aprovada (consulta #001 ao ChatGPT)

## Ambiente medido
- Zorin OS 18.1 (Ubuntu 24.04), GNOME 46, Wayland, kernel 7.0; i5 Tiger Lake 8T, 23 GB RAM, GTX 1650 4 GB.
- PipeWire 1.0.5 + WirePlumber (sem `pactl`; usar `wpctl`/`pw-cli`). Módulos: roc-sink/source (libroc 0.3), rtp-sink/source, raop, vban, pulse-tunnel.
- Zorin Connect v74 (fork GSConnect, protocolo KDE Connect, TCP/UDP 1716, transferências 1739–1764). Pareado: POCO X5 Pro 5G (phone), Galaxy Tab S10 Lite (tablet). Ambos `Connected=false` em 2026-10-24.
- scrcpy 5.0.1, adb 1.0.41, Tailscale 1.104 (pc-joao 100.77.106.53), ufw ativo (há perfil `zorin-connect`).
- Python 3.12, Node 22, Java 17, Docker, GStreamer 1.24. Sem Android SDK/Gradle/Kotlin/Flutter, Rust, Go, ffmpeg.

## Análise do Zorin Connect (REA ev_189070660c… + leitura do fonte)
- 66 módulos GJS em `/usr/share/gnome-shell/extensions/zorin-connect@zorinos.com/service`. O REA inventariou os módulos, mas não resolve imports `gi://`; a cobertura semântica ficou parcial e o restante foi lido direto no fonte.
- D-Bus: `org.gnome.Shell.Extensions.ZorinConnect`, um objeto por dispositivo em `/org/gnome/Shell/Extensions/ZorinConnect/Device/<id>`, propriedades `Connected/Paired/Name/Type`. As ações ficam em `org.gtk.Actions` (shareFile, shareUri, shareText, clipboardPush/Pull, executeCommand, ring, sendNotification, mount, ping…).
- runcommand: o celular envia só a chave UUID; o PC executa `/bin/sh -c` do comando salvo no gsettings `command-list` local e rejeita chaves desconhecidas. É o gancho seguro para "atalhos no telefone → ação no PC".
- A API não é contrato estável: o Nexus a acessa por um adaptador.

## Decisão
- Sem app Android próprio na v0.1. Base = Zorin Connect; espelhamento = scrcpy/ADB (USB primeiro); remoto = Tailscale sem portas públicas.
- Código próprio: CLI `nexus` em Python 3.12 (stdlib + gi/D-Bus) com catálogo declarativo de ações (params validados, pré-condições, permissão, timeout, log).
- Áudio: PoC Roc (roc-sink + Roc Droid 0.2.2, marcado como WIP) comparada com RTP antes de fixar. Android→PC: `scrcpy --no-video --no-control` (Android 11+).
- Fora da v0.1: app Android, Quick Settings tiles, IA, histórico unificado, automações complexas.

## Pendência bloqueante
Diagnosticar `Connected=false` antes de codificar.
